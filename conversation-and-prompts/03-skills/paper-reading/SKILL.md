# Paper Reading

## 目标与适用范围

把论文讲懂，而不是把章节摘要、原文摘抄和批评清单拼起来。用户说读 paper、精读、推荐论文、核验论文主张、走读自己的算法，都从这里进入。

**完整精读必须先加载 `limu-paper`，以其教学结构为主线。** 本入口只补取源、证据、特殊任务与交付；辅助参考不能覆盖教学主线。只要元数据、三句话摘要、BibTeX 或一个局部问题，不必启动整套精读。

用户给的文件/链接是一等信源；先检查指定版本，不拿另一版本或二手解读替代。默认中文，术语首次用人话解释。用户熟悉的背景不重复科普。

## 阅读与讲解

### 1. 确认来源和任务

确认论文标题、作者、版本及可读范围；看正文、附录、图表是否齐全。只有摘要就明确标为摘要速览，不宣布完成精读。提取缺字/串栏先修输入，不能靠模型常识补原文。

用户给了单一论文就直接读，不额外要求挑模式。交互走读一次推进一个可审对象；用户明确要求完整交付则连续完成。

### 2. 建立问题，而不是抢报结论

按 `limu-paper` 建立 **现实对象与默认做法 → 矛盾 → 研究问题 → 阅读路线**。

- 多个并列问题分别讲清，不硬造戏剧冲突或因果弧线。
- 先搞清论文到底在问什么，再解释为什么它的答案值得看。
- 保留描述性/规范性、相关性/因果性、作者主张/实际证据的区别。

### 3. 先证据，再表达；缺证据就返回取源

抽取问题、定义、实验规则、机制、关键结果、局部边界和 Conclusion，记录原文短引及真实定位。

证据不是冻结的 quote 池。写作发现前置缺失时，**重新读原文、补证据、更新阅读路线后继续**；不能用“池里没有”阻止必要补读，也不能把抽取缺失说成论文没有。

摘要、上一轮笔记和检索摘要只是导航；数字、符号、限定词、图表含义必须回原文。关键推断明确标示，不要求正文每句话挂四分类标签。证据表保留细分类，以保证可审查而不破坏阅读。

### 4. 定义先于使用，一个例子走通机制

建立前置清单：输入/输出、对象/符号、对照方法、任务/数据集、指标分母与方向、变化与固定的变量。结果里不能突然冒出未定义的比较臂。

优先使用论文或真实项目中的一个样本，追踪输入→中间状态→组件交互→输出→作用点。教学假想例子必须明确标为示意，不能冒充实验结果。并行/join/offline/online 保持真实结构。

理论论文沿一个可计算例子讲假设、命题与证明关键步；综述和立场论文改为走通分类/论证链，不虚构系统机制。所有计算用工具。

### 5. 结果按问题展开，限制就地解释

每组核心结果讲 **问题 → 比较规则 → 观测 → 解释 → 边界**，不是榜单播报。明确哪个结果支持哪个主张，哪些只是作者解释、哪些是我们的推断。

关键图表实际查看轴/图例/行列/尺度/单位/样本范围。作者声称领先时核对 baseline 与协议；差值、比例、百分点用工具重算。没有某个章节标题、seed 字样或代码链接，不触发自动弃读。

### 6. 条件化收束与审阅

结尾回答开场问题，区分可靠结论、条件性结论及仍未知的部分；不在总结里补正文没讲过的因素。

完整精读附简明 Claim–Evidence 表（无固定行数），主文仍按认知路径组织。需要研究关联时，先读当前项目材料，不继承历史 skill 中已经冻结的开题定位。

完整长文/讲稿由独立 reviewer 对照原文检查认知连续性与主张支持；失败返回原 author 修复后复审。不运行随机多次来碰一个 PASS。未能独立审阅必须说明，不能冒称 PASS。局部问答自检即可，不必多 agent。

## 交付

- **聊天问答**：直接回答当前问题，带关键原文定位；不强制建 Wiki。
- **完整精读笔记/每日选读**：保存原文来源、阅读笔记和证据，按 `references/delivery.md` 发布既定飞书目录并回读验证；失败保留本地产物并明报。
- **论文讲稿/故事**：内容仍按上述主线，制作协议由实际项目决定。没有 Paper2Story harness 时，不虚构 Document IR/sourceOrder/validator 已存在。
- 原文阅读顺序只在严格 PDF 阅读器/划线视频 profile 中强制单向；普通研究笔记允许为解释依赖回读。

## 验收

读者能回答：问题为什么成立、机制如何运行、实验比较了什么、证据支持到哪里、还有什么未证明。仅“章节齐全”“引用数量达标”“脚本退出 0”均不算通过。

检查身份/版本、前置定义、真实例子、关键图表、条件词、总结回链、引用定位与交付回读。缺全文、抽取失败、没有核过的附录和发布失败都显式说明。

## 不带回来的旧规则

- 不用关键词打分替 agent 选论文，不用固定早退比例/预算挡位替判断。
- 不把正则零命中当不存在，不把无对应证据写成已证伪。
- 不把“quote-first”吹成机制上消灭幻觉；引用匹配不代表推论正确。
- 不强制真突破/工程优化/边际改进三选一，不为填模板捏造评价。
- 不把科研价值等同于适配器现不现成，不把旧个案结论写成永久前提。
- 不把旧技能全文换个文件名搬进来；只保留与本入口一致的可复用方法。
